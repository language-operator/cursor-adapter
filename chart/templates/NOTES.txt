Cursor LanguageAgentRuntime installed.

Prerequisite: the `language-operator` chart must be installed first (it provides
the LanguageAgentRuntime CRD). Installing against a cluster without the CRD fails.

The runtime is cluster-scoped and can be referenced by LanguageAgents in any
namespace via spec.runtime:

  apiVersion: langop.io/v1alpha1
  kind: LanguageAgent
  metadata:
    name: my-agent
  spec:
    runtime: cursor

Image: {{ .Values.image.repository }}:{{ .Values.image.tag }}

Each agent serves its terminal on port {{ .Values.port }}, reachable in-cluster at
http://<agent-name>.<namespace>.svc.cluster.local:{{ .Values.port }}. From a browser it
is reached through the cluster ingress, behind the OIDC proxy when the LanguageCluster
enables auth.

Cursor does not use the model gateway: it authenticates to Cursor with a vendor
key, so spec.models does not apply to agents on this runtime.
{{- if .Values.credentials.apiKeySecret }}

CURSOR_API_KEY comes from the Secret "{{ .Values.credentials.apiKeySecret }}", which must exist
in each agent's namespace with a key named CURSOR_API_KEY.
{{- else }}

No CURSOR_API_KEY is declared. Give each agent one through spec.credentials
(valueFrom a Secret holding a CURSOR_API_KEY key), or sign in interactively in
the agent's terminal. Task-mode agents need the key: nobody is there to sign in.
{{- end }}
